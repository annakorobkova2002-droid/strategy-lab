# S5 — Analysing Resources and Capabilities

## 1. Learning objectives
- Explain the resource-based view (RBV) and why internal resources can be a more stable base for strategy.
- Classify resources (tangible, intangible, human) and distinguish them from capabilities.
- Define organisational capability, distinctive competence and core competence.
- Identify capabilities through functional analysis and the value chain.
- Appraise resources using scarcity/relevance, sustainability, appropriability and **VRIO**.

## 2. Core definitions
| Term | Definition |
|---|---|
| **Resource-based view** | Strategy is built on what the firm *has* and *can do*. When the environment changes rapidly, internal resources and capabilities are a more secure basis for strategy than a market focus. `[PN][SD]` |
| **Resources** | What the firm **has**: its productive assets. `[PN]` |
| **Capabilities** | What the firm **can do**: its capacity to deploy resources for a desired end result. `[PN][SD]` |
| **Distinctive competence** (Selznick) | Something a firm does particularly well *relative to competitors*. `[PN][SD]` |
| **Core competence** (Prahalad & Hamel) | A competence fundamental to strategy and performance. It contributes disproportionately to customer value or efficiency and gives a basis for entering new markets. `[PN][SD]` |
| **VRIO** | A test of whether a resource or capability is **V**aluable, **R**are, **I**nimitable and supported by an **O**rganisation able to exploit it. `[PN][SD]` |

## 3. Concepts explained

### 3.1 Why resources and capabilities? `[PN][SD]`
**Resources and capabilities → strategy → competitive advantage → profitability.**

The main question is: *What are we particularly good at, and where can we use it?*

Examples of capabilities reused across products and markets:
- **Honda:** engines used in motorcycles, cars, generators and marine engines.
- **Canon:** precision mechanics, fine optics and microelectronics.
- **3M:** shared technological capabilities behind many products.
- **BlackBerry** (optional case VI) `[SD]`: managers describe its real DNA as secure enterprise software and network infrastructure. That capability survived after the devices failed.

Products and markets change; strong capabilities can be redeployed.

### 3.2 Types of resources `[PN][SD]`
| Type | Examples | Key questions / notes |
|---|---|---|
| **Tangible: financial** | Internal funds, cash flow, borrowing capacity, credit rating | 1) Can the firm economise on resource use? 2) Can existing assets be used more profitably? |
| **Tangible: physical** | Plants, equipment, buildings, land, raw materials | Example: **Emirates** used passenger aircraft for cargo during COVID. |
| **Intangible: technology** | Patents, copyrights, know-how, R&D | Often the most important resources, and largely **off the balance sheet**. This is why market value can exceed book value. |
| **Intangible: reputation** | Brand, customer loyalty, company reputation, supplier relationships | |
| **Intangible: culture** | Values, norms | |
| **Human** | Skills, experience, training, adaptability, commitment, motivation, collaboration | Not on the balance sheet. |

### 3.3 From resources to capabilities `[PN][SD]`
Resources are not productive on their own. They must be **combined** through processes, organisational structure, motivation and alignment.

**Resources → integration → organisational capabilities.**

Example: skilled employees are a *resource*; the ability to develop new products quickly is a *capability*.

Capabilities form a **hierarchy** `[SD]`: from specialised, task-level capabilities, through functional capabilities, up to broad cross-functional capabilities such as new-product development.

### 3.4 Identifying capabilities `[PN][SD]`
1. **Functional analysis:** look for capabilities in each function.
   - R&D → innovation.
   - Operations → efficiency and flexibility.
   - Design → design capability.
   - Marketing → brand management.
   - Distribution → speed and customer service.
2. **Value chain analysis (Porter):** break the firm into activities and see where value is created.
   - **Primary activities:** inbound logistics → operations → outbound logistics → marketing & sales → service.
   - **Support activities:** firm infrastructure, HRM, technology development, procurement.

### 3.5 Appraising resources and capabilities `[PN]` (Grant)
1. **Establishing competitive advantage:**
   - **scarcity** (is it rare?);
   - **relevance** (does it match the industry's KSFs?).
2. **Sustaining competitive advantage:**
   - **durability** (how fast does it depreciate?);
   - **transferability** (can rivals buy it?);
   - **replicability** (can rivals build it?).
3. **Appropriating the returns (who captures the profit?):**
   - **property rights**;
   - the **bargaining power** of employees and other stakeholders;
   - **embeddedness** (how tied the resource is to the firm).

### 3.6 VRIO `[PN][SD]`
| Valuable? | Rare? | Inimitable? | Organised? | Outcome |
|---|---|---|---|---|
| No | — | — | — | **Competitive disadvantage** |
| Yes | No | — | — | **Competitive parity** |
| Yes | Yes | No | (Yes) | **Temporary competitive advantage** |
| Yes | Yes | Yes | No | **Unexploited advantage** (limited benefit) |
| Yes | Yes | Yes | Yes | **Sustained competitive advantage** |

**Imitability spectrum** `[PN]`:
- **Easy to imitate:** cash, commodities.
- **Difficult:** brand loyalty, employee satisfaction, reputation.
- **Very difficult or impossible:** patents, unique locations, unique assets.

**Purpose of VRIO** `[SD]`:
- focus strategy on the firm's most valuable elements;
- uncover the true sources of advantage;
- connect the analysis in one integrated framework.

### 3.7 Developing strategy implications `[SD]` `[TB]`
- **Exploit** key strengths: resources that are both important and strong.
- **Manage** key weaknesses: outsource, or build the capability.
- **Avoid over-investing** in strengths that are not important.

Grant draws this as a 2×2 matrix: relative strength × strategic importance.

## 6. Comparisons
| A | B |
|---|---|
| Resource: what the firm HAS | Capability: what the firm CAN DO |
| Distinctive competence: better than rivals | Core competence: central to strategy, customer value and new-market entry |
| Temporary advantage: V + R, imitable | Sustained advantage: V + R + I + O |
| Transferability: can rivals *buy* it? | Replicability: can rivals *build* it? |
| External view (S2–S4): industry | Internal view (S5): firm |

## 7. Case 2 — Sweetgreen `[PN]` class VRIO + `[REC]` context
**Context** `[REC]`:
- Sweetgreen is a US fast-casual salad chain founded in 2007 by three Georgetown graduates.
- It positions itself on fresh, locally sourced, healthy food, strong digital ordering and brand.
- It went public in 2021 and is investing in kitchen automation (the "Infinite Kitchen").

**VRIO as discussed in class** `[PN]`:
| Resource / capability | V | R | I | O | Outcome |
|---|---|---|---|---|---|
| Direct relationships with farmers | ✓ | ✓ | ✓ | ✓ | Sustained |
| Tech-driven supply chain (traceability, "blockchain") | ✓ | ✓ | ✓ | ✓ | Sustained |
| Strong brand & celebrity support | ✓ | ✓ | ✓ | ✓ | Sustained |
| Menu innovation / collaborations | ✓ | ✓ | moderate | ✓ | Temporary |
| Digital ordering / delivery | ✓ | ✗ | ✗ | ✓ | Parity |
| Cashless operations | ✓ | ✗ | ✗ | ✓ | Parity |
| Sustainable / compostable packaging | ✓ | ✗ | ✗ | ✓ | Parity |

**Critical note for open questions** `[REC]`:
- **Celebrity endorsements** can be bought by rivals, so they are arguably *imitable*.
- **Supply-chain technology** can be copied over time.
- A strong answer defends its ratings: for example, **causal ambiguity** and the time needed to build farmer networks make that resource hard to imitate.

**Lesson:** a resource can be valuable without creating advantage. If rivals can obtain or copy it easily, it only gives parity.

## 8. Practical application: VRIO in a case answer
1. List 5–7 candidate resources and capabilities.
2. Rate each on V/R/I/O and **justify** each rating in one line.
3. Conclude which ones are the source of sustained advantage.
4. Recommend: protect and exploit those; don't over-invest in parity items.

## 9. Exam traps
- **Valuable + not rare = parity**, not advantage.
- **V + R + I but not organised = unexploited** advantage, not sustained.
- Resources ≠ capabilities. "Brand" is a resource; "brand management" is a capability.
- Intangibles often don't appear on the balance sheet, which explains market-to-book gaps.
- A core competence must give access to **new markets**, not just be strong.

## 11. Memorise this
- **Resources = HAS · capabilities = CAN DO.**
- **3 resource types:** tangible (financial, physical) · intangible (technology, reputation, culture) · human.
- **Distinctive (Selznick) vs. core (Prahalad & Hamel).**
- **Identify capabilities:** functional analysis + value chain.
- **Appraise:** scarcity & relevance · durability, transferability, replicability · property rights, bargaining power, embeddedness.
- **VRIO:** not V → disadvantage · not R → parity · not I → temporary · not O → unexploited · all four → sustained.
