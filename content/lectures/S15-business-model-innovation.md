# S15 — Business Model Innovation, Value Proposition and Product–Market Fit

## 1. Learning objectives
- Design a value proposition with the Value Proposition Canvas (customer profile vs. value map).
- Distinguish push from pull innovation, and know the main ways to create customer value.
- Validate product–market fit.
- Define business model innovation (BMI) and recognise its main patterns.
- Distinguish business model from business plan, and outline a business plan, including a problem tree.
- Analyse the Netflix case.

## 2. Core definitions
| Term | Definition |
|---|---|
| **Value proposition** | The benefits and value customers can expect from a firm's products and services. `[PN][SD]` |
| **Value Proposition Canvas** | A tool to design value propositions and test product–market fit. It matches a **customer profile** with a **value map**. `[PN][SD]` |
| **Customer jobs** | Tasks customers try to perform, problems they try to solve, needs they try to satisfy. `[PN][SD]` |
| **Pains** | Anything that annoys customers before, during or after a job, or prevents the job. `[PN][SD]` |
| **Gains** | Outcomes and benefits customers want. `[PN][SD]` |
| **Product–market fit** | Alignment between the value proposition and customers' most important jobs, pains and gains. `[PN]` |
| **Business model innovation** | Enhancing advantage and value creation through simultaneous, mutually supportive changes to the **value proposition** and the **operating model**. `[SD]` |
| **Business plan** | A document describing a business, its objectives, strategies, market, outlook and financial forecasts. `[PN]` |

## 3. Concepts explained

### 3.1 Sources and types of customer value `[SD]`
Sources of an effective value proposition: **customers**, **the company's innovation**, **competitors' weaknesses**.

Nine ways to create value:
1. **Accessibility:** Zipcar.
2. **Performance:** more PC storage, more camera resolution.
3. **Customisation:** Nike custom shoes.
4. **Convenience:** iPod and iTunes, Amazon, online banking.
5. **Risk reduction:** FedEx money-back guarantee, Chevrolet's "Love it or return it".
6. **Design:** Apple.
7. **Cost reduction:** Salesforce, Skype.
8. **Low price or free:** Southwest Airlines, free apps.
9. **Innovation and newness:** video games, EVs.

### 3.2 Push vs. pull innovation `[PN][SD]`
| Push | Pull |
|---|---|
| Technology- or product-inspired | Customer-inspired |
| Starts from a solution or unique asset, then looks for applications | Starts from high-value customer jobs (important, tangible, unsatisfied, lucrative), then develops the solution |

### 3.3 The Value Proposition Canvas `[PN][SD]`
**Customer profile (the circle):**
- **Jobs:**
  - **functional** (complete a task);
  - **social** (look good, gain status);
  - **personal/emotional** (reach an emotional state).
- **Pains:**
  - **undesired outcomes, problems and characteristics** ("it doesn't work", "it makes me feel bad");
  - **obstacles** ("I lack the time");
  - **risks** ("I might lose credibility").
- **Gains:**
  - **required** (without them the solution fails);
  - **expected** (basic);
  - **desired** (beyond expectations, but wanted);
  - **unexpected** (beyond desires).

**Value map (the square):**
- **Products and services:** physical, intangible, digital, financial.
- **Pain relievers:** create savings, make customers feel better, end difficulties, eliminate risks.
- **Gain creators:** save time, money or effort; meet or exceed quality; make life easier; create positive social consequences.

**Fit:** products address important jobs, pain relievers address the relevant pains, and gain creators produce valued gains. **Rank** priorities from essential to nice-to-have. Don't try to satisfy every need.

Examples used in class `[SD]`: Taxi Service San Paolo, Tesla.

### 3.4 Validating product–market fit `[PN]`
1. **Understand customers:**
   - interview **10–20** potential customers;
   - identify segments and common jobs, pains and gains;
   - build **buyer personas**.
2. **Validate the value proposition:** does it address important needs? Will customers pay? Is it differentiated and hard to copy?
3. **Assess the fit:** compare the profile with the value map, find unaddressed needs, redesign.

Product–market fit is **iterative**: it needs continuous feedback.

### 3.5 Business model innovation patterns `[SD]` (2024–25) ⚠ verify
Changing *how* value is created, delivered or captured, not necessarily the product. Examples `[PN]`: Nespresso, IKEA, Spotify, Ryanair.

| Type | Pattern | What it does | Examples |
|---|---|---|---|
| **Frontstage** (who and how value is delivered) | **Market explorers** | Open new, untapped or underserved markets | Tesla, iPhone, Wii (via BOS); M-Pesa, AWS (new tech for proven demand); Azuri (accessibility); Hilti (servitisation) |
| | **Channel kings** | New ways to reach many customers | Dollar Shave Club (marketing); **Velasca**, Hilti (disintermediation, direct channel); Tupperware (others sell for you: home parties) |
| | **Gravity creators** | Lock customers in with switching costs | Microsoft Windows; Nespresso |
| **Backstage** (how value is created) | **Resource castles** | Hard-to-copy resources | Waze (network effects); Dyson (IP and R&D) |
| | **Activity differentiators** | New activity configurations | Ford Model T (efficiency); Zara (speed); Patagonia (environmental); Dell (build-to-order) |
| | **Scalers** | New ways to scale | IKEA, Facebook (others do the work); Disney (licensing); McDonald's (franchising) |
| **Profit formula** (revenues and costs) | **Revenue differentiators** | New ways to capture value | Spotify (freemium); Gillette (razor-blade); Azuri (upfront fee, subsidised price) |
| | **Cost differentiators** | New cost structures | (named only) |
| | **Margin masters** | Higher margins | (named only) |

**Tupperware** `[SD]`, a channel-king story:
- after the Second World War, Brownie Wise built home "Tupperware parties" run by independent women dealers;
- by 1954 the network had about 20,000 dealers;
- in-store sales were dropped in 1951.

**Patagonia** `[SD]`:
- activities designed around environmental protection;
- 100% organic cotton from 1994;
- its 2018 mission: "We're in business to save our home planet".

### 3.6 From idea to business plan `[PN]`
**Business idea** (opportunity) → **business model** (value logic) → **business plan** (execution and forecasts).

| Business model | Business plan |
|---|---|
| Value creation and capture | Objectives, strategy, operations, financial projections |
| A synthetic framework | A detailed document |
| Developed through iteration | Describes execution and forecasts |
| The business logic | Qualitative and quantitative analysis |

**Purposes of a business plan:**
- **external:** convince investors and stakeholders;
- **internal:** planning, coordination, decision-making.

**Structure:**
- executive summary;
- (1) business overview;
- (2) market opportunity;
- (3) market solution;
- (4) market and competition;
- (5) marketing plan;
- (6) implementation roadmap;
- (7) management team;
- (8) financial analysis;
- (9) social and environmental impact;
- (10) risk analysis;
- (11) funding request.

**The executive summary:**
- the "business card" of the plan;
- at most 2–3 pages;
- future-oriented (potential and returns);
- ends with a request.

**Market opportunity and the problem tree:** **root causes → core problem → consequences.** Understand the causes before designing the solution.

**Market solution:**
- features and tangible and intangible benefits;
- connected services;
- a working model or prototype;
- barriers to entry.

The aim is to show feasibility.

## 4. Case 7 — Netflix (required) `[PN]` + `[REC]`
**Evolution of the business model** `[PN]`:
1. DVD rental by mail.
2. A **subscription** with unlimited rentals (no late fees).
3. Online **streaming**.
4. **Original content** production (vertical integration).
5. **Binge release** of full seasons.
6. Direct online film distribution.

**Theory links:**
- **BMI:** repeated redesign of how value is delivered (mail → streaming) and captured (subscription).
- **Revenue model:** subscription. Recently also an advertising tier and paid account sharing `[REC]`.
- **Vertical integration** into content reduces dependence on studios, which are both suppliers and competitors.
- **Differentiation:** originals, recommendation algorithms, convenience.
- **Blue Ocean / industry evolution:** Netflix made Blockbuster's model obsolete. This links to Judo strategy in S19 and DVD decline in S8.

**Reading C**, "Will Netflix become the next Blockbuster?": the question is whether rising competition (Disney+, Amazon, others), content costs and saturation could turn the disruptor into the disrupted. `[REC]`
- The tension: Netflix's model is **imitable**.
- Its advantage now depends on scale, data, original IP and global reach.

**Luke's Lobster** (lecture example) `[PN]`:
- sustainable, traceable Maine seafood;
- simple counter-service formats keep overheads low;
- **vertical integration** from sourcing to serving supports quality, traceability and efficiency.

## 6. Comparisons
| A | B |
|---|---|
| Customer profile: jobs, pains, gains | Value map: products, pain relievers, gain creators |
| Push: technology first | Pull: customer first |
| Required / expected gains | Desired / unexpected gains |
| Frontstage BMI: who and how delivered | Backstage BMI: how created · profit formula: revenues and costs |
| Business model: logic | Business plan: execution and forecasts |
| Root causes | Consequences (problem tree) |

## 7. Exam traps
- **Pain relievers** match **pains**; **gain creators** match **gains**. Don't cross them.
- BMI does **not** require a new product (Nespresso, Ryanair).
- Product–market fit is **iterative**, not a one-off test.
- The executive summary comes **first** but is written to summarise the whole plan.
- A problem tree starts from **causes**, not solutions.

## 9. Memorise this
- **VPC = customer profile (jobs, pains, gains) + value map (products, pain relievers, gain creators).**
- **Jobs:** functional · social · emotional. **Gains:** required · expected · desired · unexpected.
- **Push = solution first; pull = problem first.**
- **PMF validation:** interviews (10–20) → personas → validate → assess fit → iterate.
- **BMI patterns:** frontstage (explorers, channel kings, gravity creators) · backstage (resource castles, activity differentiators, scalers) · profit formula (revenue, cost, margin).
- **Idea → model → plan.** **Problem tree:** causes → core problem → consequences.
- **Netflix:** DVD mail → subscription → streaming → originals → binge.
